# 三国ドロケイ v7.19 (3D)

太陽・月・星の三国で敵国の王を探し出して捕らえる、ブラウザ向けの3Dドロケイゲームです。
舞台は夕暮れの東京（山手線の内側）。各国の拠点に立つ光の柱、国境に光る前線、画面の拠点マーカー、街に掛かる支配国の色の幟で戦況が見えます（v7.14〜7.15）。
建物や木の陰に入ると自キャラは国の色のシルエットで透けて見えます（v7.15）。
v7.0 はゲーム内容を v6 のまま、Vite + TypeScript + Three.js (npm) + Vitest の構成へ移しました。

## 起動

```bash
npm install
npm run dev      # http://localhost:5173/
```

| コマンド | 内容 |
|---|---|
| `npm run dev` | 開発サーバー |
| `npm run build` | 型チェック + 本番ビルド (`dist/`) |
| `npm run preview` | ビルド結果の確認 |
| `npm run test` | Vitest |

操作（PC）: ↑↓ 前進・後退 / ←→ 旋回 / Shift 加速 / Space 捕獲 / Z 特殊（救出できる人は牢屋の仲間のそばで救出） / Q 180°振り向き / B 管制塔で王を照らす / 分隊: X 付いてこい・C 周りを警戒しろ・V ここを守れ / ドラッグで上下の傾き・ホイールで距離

操作（スマホ）: 左下ジョイスティック（上下で前後、左右で旋回）、右下の 捕獲・特殊・ダッシュ・振向、画面の上下スワイプで傾き。
上部の「情報」でミニマップ・王候補、「ログ」で戦況ログを開閉。

カメラは常にキャラクターの背後にあり、背中側は見えません（背後を取るゲームなので）。確認したいときは Q で振り向きます。
階段・坂で2階・屋上・高台・見張り台へ上れます。足元の水色の弧が「正面」（この範囲の敵からは捕獲されない）、
緑〜橙のリングは今捕獲ボタンを押すと狙う相手です。

### 東京戦区と三国の戦争（v7.13）

勝敗は今まで通り **王の捕獲と処刑だけ** で決まります。戦区は、戦闘・王探し・情報のための仕組みです。

- 山手線内を 9 つの戦区に分割: 新宿・渋谷・池袋（太陽） / 上野・秋葉原（月） / 東京タワー・品川（星） / 文京・中央（中立）
- 各戦区に旗の立つ **戦略拠点**（新宿御苑前・スクランブル交差点・池袋駅前広場・東京ドーム前・上野の山（高台）・電気街・日比谷公園・東京タワー下・品川駅前）。
  1 国だけで立ち続けると制圧ゲージが進み（1 人 10 秒、人数が多いほど速い）、他国もいれば **交戦中（CONTESTED）** で止まる。持ち主が立つとゲージが戻る
- 違う国の戦区が接する境界が **前線**。ミニマップに勢力の薄い色・前線（赤い線）・拠点（持ち主の紋章と制圧ゲージ、交戦中は点滅）
- 各国の司令（国家戦略）: 戦区侵攻・戦区防衛・管制塔奪取・王の捜索・王の救出・捕らえた王の防衛・漁夫の利・態勢の立て直し
  - 兵士・遊撃兵は拠点へ進軍（一部は階段・歩道橋・高台の別ルートから）、狙撃手は近くの屋上・歩道橋・高台から援護、鍵使いは前線の少し後ろで待機、
    通信士は管制塔か後方、王は安全な自国領を移動（護衛は少し離れて付く）
  - 第三国は、戦っている二国の負けている側を後ろから突く・空いた戦区を取る・管制塔を奪う・牢屋戦に乱入する
  - 王が捕まると: 捕まった国は救出（前線は縮小して守る）、捕らえた国は牢屋と前線の両方を守る、第三国は漁夫の利。牢屋の位置は全勢力に公開
- **一時停戦**: 一国が突出すると、残り二国が 45 秒だけ互いに捕獲しない停戦を結ぶことがある（1 試合 2 回まで）。
  あなたの国への申し出は「承諾／拒否」で答える。上部の「停戦」ボタンで自分から申し出ることもできる
- 管制塔を持ち通信士がいる国は、交戦中の拠点にいる敵の人数（ミニマップ）と他国の作戦（ログ）が分かる
- 画面上の紋章マーカー（v7.15）: 拠点の持ち主・制圧ゲージ（輪）・戦区名と距離・交戦中。近い 3 つと交戦中・制圧中の拠点は画面外でも端に矢印で出る
- 街灯と建物の正面の幟の色 = その戦区の支配国（v7.15）
- 水に落ちても岸に上がれる（動けなくならない）。神田川の橋はすべて歩いて渡れる（v7.16）

### 友達と遊ぶ（オンライン, v7.11）

- スタート画面の「友達と遊ぶ」で **部屋を作る** → 表示された部屋コード（5 文字）を友達に伝える。友達はコードを入れて **参加**
- 全員が上で国と役職を選ぶ（同じ国なら味方、別の国なら敵）。人数はホストが選んで「みんなで開始」。最大 9 人、残りは AI
- 友達の頭上に名前が出ます。ハーフタイム会議は国ごとに開かれ、同じ国の人の投票の多数決で捜索先が決まる（全員が「会議を終える」か 30 秒で再開）
- 緊急会議はオンラインでは使えません（全員の試合が止まるため）
- 使える条件: claude.ai 上でこのページ（Artifact）を開いていること。友達は **共有メニューから招待** されたアカウントで開く必要があります
  （公開リンクで開いた人・保存した HTML ファイルでは接続できません）
- ホストがゲームを進め、約 10 回/秒で状態を送ります。ホストがタブを閉じると試合は終わります。途中で抜けた人のキャラは AI が引き継ぎます
- 各自の移動は自分の端末で計算します（遅延なし）。捕獲・スタン・牢屋はホストが判定します

### 分隊

- あなたには 2〜4 人の分隊が付きます（兵士優先）。X「付いてこい」（歩き続けても付いて来る）／C「周りを警戒しろ」（あなたを囲んで外側を見張る）／V「ここを守れ」、スマホは「分隊」ボタン
- AI も 2〜3 人の小隊で動き、止まると前後左右を分担して見張ります

### 役職の追加・変更（v7.12）

- **遊撃兵**（詐欺師の代わり）: 機動・追跡・救援。スタミナの回復が速く、階段や坂でも速度が落ちにくい（ほかの役職は上りで約2割遅くなる）。
  特殊「疾走」: 4.5 秒間 速さ×1.3・スタミナ回復アップ（再使用 16 秒）。耐久・捕獲性能は普通。
  AI は捕獲の起きた場所や最新の目撃地点へ駆けつけ、ほかの味方が追っているときは階段の出口や橋へ先回りする
- **王のスーパーハンド**: 王は正面からでも確実に捕まえられる
- **王が処刑されたら国ごと敗北**: その国の全員が処刑され、その国の牢屋にいた捕虜は解放される

### 観戦（幽霊）

- 処刑されると幽霊になり、壁も建物も抜けて自由に飛び回れる。全員の姿が見える
- ↑↓ で見ている方向へ進む（ドラッグで上下を向けば上昇・下降も）、←→ で向き、Shift で速く、Space で上昇・Z で下降

### 狙撃手

- ライフルで前方±30°・約 20 m 先の敵を撃ち、3 秒スタン。高所から撃つと射程 +25%
- 命中する相手がいると赤いレーザーと照準リングが出る。外しても装填は減らない。装填 8 秒
- 敵の狙撃手に狙われると赤いレーザーが見える

### 会議

- **ハーフタイム会議**: 経過 2:30 に 1 回、全員参加（その間は全員停止、32 秒で終了・オンラインは 40 秒）。戦況と目撃情報を共有し、次の重点捜索先に投票
- 会議では仲間が名前付きで順番に発言し、意見を言い合う（賛成・慎重論・反論・まとめ）。あなたの発言や投票にも返事をする
  - 捕まった王や仲間の話が最優先。そのあと目撃情報に加えて、戦区の戦況・国の作戦・停戦・犠牲・活躍した仲間・残り時間・管制塔・容疑者・雑談から毎回違う話題を選ぶ（v7.18）
  - 同じ試合で同じセリフは繰り返さない。性格（強気・慎重・分析的）で言い方が変わる
- **緊急会議**: 自国拠点の近くで 1 試合 2 回まで開ける（拠点が一時的に敵に見える代償あり）

### 味方の名前と役職（v7.18）

- 自国の仲間の頭上に名前と役職を表示（王は金色）。遠くでは名前だけ、牢屋にいる仲間は（牢）。敵の役職は表示しない
- オンラインでは、別の国の友達はニックネームだけ表示

### 牢屋と処刑・救出（v7.18〜7.19）

- 捕まると牢屋へ。処刑までは 50 秒、王は 80 秒。捕まった王の牢屋は 45 秒間、全勢力に公開
- 救出できる人（牢屋の仲間のすぐそばで Z）: 鍵使い、**王（いつでも）**、**国で動ける最後の一人（役職に関係なく）**。鍵使い以外は解錠に 1.5 倍かかる
- 救出できるときは画面下に「🔑 救出能力あり」、牢屋の仲間のそばでは「🔑 Zで○○を救出！」。最後の一人になるとバナーで知らせる。味方の名札にも 🔑
- 捕縛・処刑・救出はログと右の「捕縛・救出・処刑」欄に名前付きで出る（「○○が月国に捕まった！ 太陽：動けるのは4人（牢2・処刑1）」）。自国の出来事は画面上部にも通知
- 右の「各国の残り」: 国ごとに動ける人（●）・牢屋（○）・処刑（灰）
- 王候補（推理）欄と【推理】ログは廃止

### 管制塔で王を照らす（v7.19）

- 残り時間が 3 分の 1（1:40）を切ると、管制塔を持つ国は **敵国の王の位置を 12 秒間照らせる**（B キーか上部の「王を照らす」、再使用 40 秒）
- 照らされた王の上には金色の光の柱、ミニマップには ♛。照らされた側にも通知が出る。AI の国も管制塔を持てば使う

### 人々（v7.6）

- 開始画面で各国の人数を 6 / 10 / 15 人から選べます（標準は 10 人）
- 全員が実物の頭身の人物で、国の色の法被とはちまきを着ています。背中には国の紋（背中側から捕まえるゲームなので目印）
- 歩く・走る・止まる・見回す・振り向く・よろめく・座る（牢屋）・しゃがむ（解錠）・腕を伸ばす（捕獲）の動きがあります

### マップ（v7.5）

舞台は東京・山手線の内側。駅と名所は実際の緯度経度から配置しています。

- **人・建物・道路は実物大の比率**（キャラクター ≈ 1.7 m ≈ 45 単位、1 m ≈ 26 単位）。1 階 4.2 m・2 階以上 3.3 m の階高、
  2 車線道路 ≈ 9 m、路地 ≈ 4.6 m、4 車線の大通り ≈ 15 m、歩道・縁石・点字ブロック、電柱（10 m）、自販機、駐車車両まで同じ比率
- **街と街の距離だけ縮めています**（1 m = 1.0 単位）。実物の山手線の内側は徒歩 1 時間以上かかるため、ブロックの数を減らしています
- 100 m を超える超高層（東京タワー・サンシャイン 60 など）は 100 m から上を 4 割に圧縮
- 太陽国 = 新宿三丁目、月国 = 上野広小路、星国 = 高輪。管制塔 = 日比谷公園の電波塔（三拠点からほぼ等距離）
- 街区は地区ごとに自動生成: 新宿・渋谷・池袋・秋葉原などは雑居ビルと袖看板、丸の内・六本木はオフィス、文京・白金は戸建てとマンション
- 名所: 皇居と堀、皇居前広場、東京駅丸の内駅舎、国会議事堂、東京タワー（フットタウン屋上まで外階段）、愛宕山の石段、
  上野の山、不忍池、神田川と聖橋、東京ドーム、国立競技場、首都高（大通りの上の高架を歩ける）、歩道橋、アメ横風アーケード
- 線路の外は景色のみ（高架の山手線と電車、西新宿の超高層ビル群、都庁、スカイツリー）

`npm run build` 後の `dist/index.html` は1ファイルで完結しており、ダブルクリックでそのまま遊べます。

`?debug` を付けて開くと、自動テスト用の読み取り専用フック `window.__sangoku` が有効になります。

## 構成

```
legacy/                 v6 の単一HTML（比較用・削除しない）
src/
  main.ts               組み立て（状態・描画・UI・入力をつなぐ）
  config/               国・役職・マップ（箱と坂でできた立体ワールド）・バランス定数
  core/                 clock（固定ステップ）/ loop（rAF）/ events（EventBus）/ rng
  sim/                  ゲーム状態とルール。DOM・Three.js・音声に触れない
    war.ts              東京戦区（戦区・戦略拠点・制圧・前線・停戦・国力）
    state.ts entity.ts events.ts step.ts game.ts
    systems/            world（高さ・衝突・見通し）movement collision vision capture jail rescue tower
                        randomEvents suspicion winCondition abilities
  ai/                   nav（経路網 + A*）/ perception（視野・見通し・足音）/ controller（追跡・捜索・護衛・救出）/ faction（三国の司令）/ strategy（国家戦略）
  meeting/              会議のロジック（ハーフタイム・緊急、オンラインは国ごと）
  net/                  オンライン対戦: snapshot（状態の圧縮・ミラー）/ online（ロビー・ホスト・参加者の通信）
  input/                キーボード + Pointer Events → 軸 / コマンド
  render/               シーン構築（空・地形・城壁・楼閣など）・キャラ表示・カメラ・地面マーカー・生成テクスチャ
  ui/                   HUD・ログ・ミニマップ・各画面・ドロワー・イベント→文言
  audio/sfx.ts          効果音
tests/                  Vitest
tools/character-preview 開発用のキャラクター一覧（`npm run dev` 中に /tools/character-preview.html、?back ?side ?face ?pose=walk|behind|fold|winded）
```

### 設計ルール

- **ゲーム時間は `state.time` だけ。** 60Hz の固定ステップ (`stepSimulation`) でのみ進むため、
  会議中・ゲーム終了後・タブ非表示中は牢屋・スタン・偽装・レーダー・イベント・クールダウンが全て止まる。
- **sim は出来事を `GameEvent` として `state.events` に積むだけ。**
  UI・音声がそれを受けてログ・バナー・効果音を出す（`ui/messages.ts`, `audio/sfx.ts`）。
- 描画は状態を毎フレーム読み取り、ステップ間を補間して表示する。
- `tests/architecture.test.ts` が sim/ai/meeting/core/config から three・DOM・音声・実時間タイマーを使っていないことを検査する。
