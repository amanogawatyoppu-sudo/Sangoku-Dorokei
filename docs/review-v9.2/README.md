## 1. キャラクター（SOL RUNNER 見本）
- 約5.7頭身（テストで 5.2〜6.4 の範囲を確認）。大きく読める目と眉、曲面と平面を混ぜた顔、束感のある髪（1本ずつの房）
- 黒〜チャコールのジャケット（裾が脚の動きで揺れる）、オレンジの襟・袖口・発光ライン、厚底スニーカー、左手首の TRACE DEVICE、イヤーピース、背中の小型ユニット。銃なし
- 発光ラインを少し深い色にした。v9.1 は SOL の発光ラインが白飛びして黄色（STAR）に見えていた（`1-character-turnaround.jpg` 上段）
- アニメーションは既存の歩き・走り・ダッシュ・旋回・停止をそのまま使用（入力・速度は変更なし）。新しい脚の長さで足が地面に届き、めり込まないことをテストで確認
- 役職隠し（v9.1 のルールのまま）
  - 制服・髪・顔は id だけで決まり、役職で変わらない（6役職 × 5人で頂点・色・インデックスまで一致）
  - ANCHOR 専用の髪型・背中ユニット・アニメーションはない。ANCHOR の自陣向けの装備は VANGUARD か RUNNER と完全に同じ
  - 変装・陣営切替で体全体が塗り直され、元の陣営色は残らない（その陣営で最初から作った体と一致）
  - 敵に ANCHOR の装備が見えることはない。味方の役職表示と v9.1 の一時表示はそのまま
- カメラ（試作時のみ）: 距離 160 → 145、傾き 0.42 → 0.34。プレイヤーの画面上の高さは 1366×768 で 699px 中 120px（17%）→ 135px（19.3%）。前方の道と逃げ道は見える（`3a`, `3b`）。ズーム・傾きは従来どおり操作できる

## 2. 渋谷ブロック「NEON MAZE」
場所: スクランブル交差点（x −2700, z 1899）と、その東の2街区・南西のガラスタワー・西の高架。
- 店先: 間口ごとのショーウィンドウ（カフェ・雑貨・ゲームセンター・靴・レコード・本・服など8種）、店名の帯（すべて架空の名前）、日よけ、柱
- 看板: 縦の袖看板（建物の高さに応じて）、角の建物は階ごとの光のライン、大型ビジョン3面（交差点に向けて、路上のカメラから見える高さ）と文字が流れる帯
- 地面: スクランブルの斜め横断歩道、店先の御影石の帯、角の石畳、街路樹と植え込み、ガードレール（角だけ）
- 誘導: 歩道橋の階段2か所に「歩道橋」看板と足元のミントの光の線、南の路地に「路地」看板と提灯の門、交差点に「スクランブル」看板
- 「大きな暗い壁」: 西を向いたときに見える **山手線の高架**（アーチがほぼ全面暗い色）。建物・当たり判定・カリングの問題ではない。地形は消さず、渋谷駅前後の高架アーチ（内側）に明るいガード下の店（自転車置き場・スタンド・飲み屋・シャッター）をはめ込んだ（`4` の D 列）
- カメラの遮り: 張り出した袖看板・日よけ・柱・植え込みがカメラとプレイヤーの間に入ると、街路樹と同じ方式で細かく透ける（v9.1 では C 地点で青い看板が画面を覆っていた）
- 色の分離: 看板・画面の光はマゼンタ・紫・ミント・ローズ・白だけ。各陣営の色相から 24°以上離れていることをテストで確認。試作時は渋谷戦区の既存の光と袖看板からも黄・青を外した
- すべて見た目だけ（ワールドのデータは不変をテストで確認）。5回の描画にまとめ、テクスチャは1枚（1024×1280）
